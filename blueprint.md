# Pixel Art Editor

## Overview

This is a web-based pixel art editor that allows users to create and download their own pixel art. It features a grid-based drawing canvas, a color palette, an eraser, and a reset function.

## Design and Features

### Styles and Design
*   **Layout:** A simple, centered layout with the grid taking up the most space.
*   **Color Palette:** A palette of cute and retro colors.
*   **Grid:** A checkerboard-like grid.
*   **Buttons:** Styled buttons for controls.
*   **Typography:** A pixel-art-style font.

### Features
*   **Drawing:** Click on grid cells to color them with the selected color.
*   **Color Selection:** Choose a color from the palette.
*   **Eraser:** An eraser tool to clear individual cells.
*   **Reset:** A button to clear the entire grid.
*   **Download:** A button to download the created artwork as a PNG file.
